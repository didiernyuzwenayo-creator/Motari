# MOTARI

Live website: https://didiernyuzwenayo-creator.github.io/Motari/

MOTARI connects motorcycle-taxi riders and passengers in Rwanda. It uses Supabase for authentication and data, and Leaflet/OpenStreetMap for the map.

See [README_RW.md](README_RW.md) for setup, current functionality, and manual testing steps.

Important: the implementation has been checked against the connected Supabase schema and policies, but a full two-account, two-device GPS/ride test still needs to be completed before real-world use. Never put a Supabase service-role or secret key in browser code.
